Sketchpad's TX-2 display service drawing on the oscilloscope

This page shows a picture drawn by original 1962-63 Sketchpad code (the sequence-60 oscilloscope display service SQ60A...SQ60FEW from the LMH Y3HT listing, CHM cat. 102726903 vol. 2, transcribed in TX-2/Sketchpad sk2.tx2as lines 5376-5512). The code runs unaltered on a TX-2 simulator; every mark below is a real TSD display transfer to unit 60 (Users Handbook unit sheet "No. 60 OSCILLOSCOPE DISPLAY", word format per Lincoln Lab TR-296 Fig. 4.5). The square is drawn the way Sketchpad draws lines: a chain of spots one memory word each (TR-296 section 5); each spot is intensified 8 times per pass by the original's fewer-than-50-point brightening loop.

Scope face (1024x1024 raster, origin at centre)
